# 方法与评价协议

## 任务

输入单张图片，输出舰船边界框、17 类中的类别和检测置信度。16 类为预定义舰级或批次，第 17 类为 `other_ship`。YOLO 标注编号 0～16，COCO 标注编号 1～17；顺序固定，见 `configs/dataset.example.yaml`。

`ship_knowledge.yaml` 是教师资料中的类别级文本知识，不是每张图片的配对说明。模型输入只包含图像像素和固定候选文本，不读取文件名中的类别文字。

## 训练与推理

1. 从 COCO 预训练参数初始化 YOLO11n / YOLO11s，微调 17 类检测器。
2. 推理对候选框进行类别相关 NMS：IoU=0.7，每图最多 100 框，每个候选只选择一个类别。
3. 对预测框增加 5% 上下文，裁剪区域并放入灰色正方形画布，使用冻结的 OpenAI CLIP ViT-B/32 编码。
4. 文本一组仅包含自然语言类别名称，另一组在同样名称后追加教师 `prompt` 字段。使用预训练的固定 logit scale 计算相似度。

对于原本预测为具体舰级的目标，计算：

```text
g[c] = (1 - alpha) * log(max(yolo_score[c], 1e-10))
       + alpha * clip_logit[c]
final_class = argmax(g), c = 0..15
```

`alpha=0` 完全恢复基线标签。原本预测为 `other_ship` 的目标保留该标签；最终检测框和置信度保持不变，也不额外做融合后 NMS。这是检测后的类别重判，未对 CLIP 进行本任务联合训练。

内部验证搜索集合为 `0, 0.05, 0.1, 0.2, 0.35, 0.5, 0.75, 1.0`。以 COCO mAP@0.5:0.95 选择权重，并列时取较小值；额外固定 `alpha=0.25` 作为正权重对照。模型规模通过请求范围内各种子内部验证均值选择。

## 数据划分

原始数据：1,868 图、2,233 框、17 类。检查图片可读性、尺寸及 YOLO / COCO 一致性后，对 31 个最大约 0.113 像素的边界偏差进行裁剪，在派生数据中同步两套标签。

近重复筛查使用 SHA256，或同时满足 pHash 汉明距离≤4、dHash≤6、长宽比对数差<0.08。原实验共发现 3 对候选，均经人工查看；其中 1 对跨原 train / val，从训练侧排除。原训练集内部近重复组整体分配到同一子集。

| 训练 | 1,275 | 1,542 |
| 内部验证 | 215 | 274 |
| 最终评估 | 377 | 416 |

原 `val` 留作最终评估，内部验证从原 `train` 中划出，固定数据划分种子为 42。准备脚本生成近重复复核图，使用其他资料时也应检查自动筛查候选。

## 指标

- 最终检测 AP：pycocotools，IoU=0.50:0.05:0.95，置信度下限 0.001，maxDets=100，101 点插值。
- 工作点诊断：置信度 0.25、IoU≥0.5，先进行类别无关的一对一空间匹配，再统计类别是否正确，给出 P/R 和匹配后分类正确率。
- 诊断匹配与 COCO 按类别计算 AP 的过程不同；P/R 不是对 COCO AP 的另一种写法。

Ultralytics 原生验证使用 `multi_label=True`，实际预测及最终融合使用 `multi_label=False`。检查点按原生内部验证指标选择，但模型规模、文本权重和所有最终对照统一使用单类别预测的 COCO 指标。原实验用完整 215 张内部验证图确认：官方单类别预测与自定义预测器的 COCO mAP 均为 68.879659%（YOLO11n、seed=42），完全一致。

## 限制

摩耶级最终评估只有 1 个目标，伯克 Flight III 只有 2 个；单类指标不稳定。近重复筛查不等于按拍摄来源或场景严格分组，当前没有外部测试集。三个种子的标准差仅反映训练随机性。通用 CLIP 与专业舰级存在分布差异，相似或不可见的外观细节会限制文字作用，且无法核查预训练数据是否与这些图片重合。

参考方法：[YOLO](https://arxiv.org/abs/1506.02640)、[YOLO11 官方文档](https://docs.ultralytics.com/models/yolo11/)、[CLIP](https://arxiv.org/abs/2103.00020)、[COCO](https://arxiv.org/abs/1405.0312)。
